# Security Policy

## Supported versions

TempoFlow is pre-alpha. No release currently receives production security support.

| Version | Supported |
|---|---|
| Unreleased development branch | Best effort |
| Published releases | None yet |

## Reporting a vulnerability

Do not open a public issue. Use [GitHub private vulnerability reporting](https://github.com/jfheinrich-eu/tempoflow/security/advisories/new).

Include the affected revision, environment, reproduction steps, impact, a proof of concept where safe, and suggested mitigation. Do not include unrelated personal data or third-party copyrighted material.

Maintainers will investigate privately and coordinate disclosure after a fix is available. This pre-alpha project cannot promise a fixed response deadline.
