# Support

TempoFlow is pre-alpha and has no production support commitment.

- Use [GitHub Discussions](https://github.com/jfheinrich-eu/tempoflow/discussions) for questions.
- Use the appropriate [issue template](https://github.com/jfheinrich-eu/tempoflow/issues/new/choose) for confirmed bugs or proposals.
- Use [private vulnerability reporting](https://github.com/jfheinrich-eu/tempoflow/security/advisories/new) for security issues.

Provide the repository revision, Windows and Cubase versions, build configuration, sample rate, buffer size, and minimal reproduction steps. Never post credentials or private project data.
