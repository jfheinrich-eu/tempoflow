Open source · Pre-alpha

Sample-accurate metronome tools for musicians.

TempoFlow is building a host-synchronized VST3 plug-in and a portable preset format for reliable tempo, meter, accents, and click sounds.

View the source Read the preset specification

Product direction

One musical contract, two focused tools

01

VST3 plug-in

The first engineering target is a native Windows x64 plug-in for Cubase Elements 15, synchronized to host transport and timing.

02

Portable presets

The versioned .tempoflow JSON format describes tempo, meter, grouping, beat roles, sound selection, and playback mode.

03

Shared semantics

Native and browser applications share the schema, semantic rules, validator behavior, and reference presets—not application code.

Current status

Foundation in place. Audio engine next.

The repository currently contains the preset specification, JSON Schema, semantic validator, seven reference presets, Windows build setup, automated tests, security checks, and coverage reporting.

The VST3 processor and audio callback are not implemented yet. Do not use the project as a production plug-in or depend on API stability.
