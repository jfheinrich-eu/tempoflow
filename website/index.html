Sample-accurate metronome tools for musicians.

TempoFlow is a working host-synchronized VST3 metronome prototype built around a portable preset format for tempo, meter, grouping, accents, and click sounds.

Product direction

One musical contract, two focused tools

01

VST3 plug-in

The native instrument follows host transport, tempo, meter, PPQ, and buffer position. Windows x64 with Cubase Elements 15 is the primary validation target.

02

Portable presets

The versioned .tempoflow JSON format describes tempo, meter, grouping, beat roles, sound selection, and playback mode. Seven reference presets also generate native VST3 factory presets.

Preset Format 1.0 →

03

Shared semantics

The planned browser application and native plug-in share the schema, semantic rules, validator behavior, and reference presets—not application code or runtime dependencies.

Current status

Working prototype. Release work remains.

The VST3 processor, sample-accurate host synchronization, synthetic click engine, grouping-aware playback, project-state restoration, semantic preset validation, and native factory-preset generation are implemented and covered by automated tests.

Cubase Elements 15 discovers all seven factory presets, exposes their catalogue metadata, and restores user presets and project state. Windows x64 and unsigned macOS Universal builds are supported.

Audible triplet subdivisions, the complete Cubase validation matrix, a Windows installer, and final release verification are still open. There is no production release or supported binary download yet.
